# TikGrap

Next.js + React TikTok downloader (video no watermark, MP3, photo slideshow) with a neo-brutalist UI.

```bash
npm install
npm run dev      # http://localhost:3000
```

Deploy: push to GitHub, import the repo in Vercel (framework: Next.js). The API lives in `app/api/download/route.js`.
